# between pages and flowers

A reading journal by Amy U.: books, flowers, and the cafés in between.

Live at https://yummyamy.github.io/between-pages-and-flowers/

Pages: `index.html` (home), `shelf.html`, `journal.html`, `flowers.html`, `cafes.html`.
Photos and video live in `assets/`. `js/dc-runtime.js` runs the interactive parts; `js/morphdom-umd.min.js` is the MIT-licensed morphdom library.
